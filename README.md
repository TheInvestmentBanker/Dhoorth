# Independent Publication — MERN + MUI

A responsive independent news/analysis publication with a React/MUI frontend and Express/MongoDB backend.

## Run
Backend:
`cd backend && npm install && copy .env.example .env && npm run seed && npm run dev`

Frontend:
`cd frontend && npm install && copy .env.example .env && npm run dev`

Frontend: http://localhost:5173
Backend: http://localhost:5000

The public brand remains `PUBLICATION_NAME`. Theme colors are centralized in `frontend/src/theme/theme.js`.
